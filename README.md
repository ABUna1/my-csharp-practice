# C# Practice Projects

C# 学習用の練習プロジェクトをまとめたリポジトリです。

Microsoft Learn の C# 学習内容をベースに、基本文法からコンソールアプリ作成まで段階的に練習しています。

---

- 基本的な値の扱い

### 02_CreateBuildRunConsoleApp
- コンソールアプリ作成
- dotnet CLI
- ビルド・実行方法

### 03_ConditionalLogic_DiceGame
- if 文
- 条件分岐
- サイコロゲーム作成

### 04_SubscriptionRenewalRules
- Boolean 型
- 条件式
- 更新ルール判定ロジック

### 05_ArraysAndForeachPractice
- 配列
- foreach 文
- 配列データの処理

### 06_CSharpCommentsPractice
- 1行コメント
- 複数行コメント
- コード説明の書き方
